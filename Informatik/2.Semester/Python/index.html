Listen, Dict, Sets & f-Strings

🧠

Aufgabe 1 ist ein Sammelsurium kleiner Grundlagen-Fragen. Jede Teilaufgabe ist in ein bis zwei Zeilen lösbar – die Punkte holt man über Vollständigkeit und bei „Zusatzpunkt für jede weitere Art“ über mehrere Lösungswege. Deshalb lohnt es sich, pro Teilaufgabe zwei, drei Varianten parat zu haben.

Regeln

2 · SlicingL[start:stop:step] – L[::-1] läuft rückwärts und liefert eine neue Liste.

6 · Dict-Zugriffd[k] wirft KeyError · d.get(k) gibt None · d.get(k, default) gibt default
7 · Format-Spec{wert:[füll][<>^][+][0][breite][,][.präzision][typ]} mit Typ d f e % x b o s

▸ Beispielaufgabe · f-Strings Schritt für Schritt

Gegeben a = 100 und b = 2.57878. Gesucht sind ' 2.58' und 0000100.

Schritt 1 · Nachkommastellen

.2f bedeutet: als Kommazahl mit genau 2 Nachkommastellen, gerundet. Aus 2.57878 wird "2.58" – das sind 4 Zeichen.

Schritt 2 · Mindestbreite

Das gesuchte Ergebnis hat 5 Zeichen (Leerzeichen vorne). Die Zahl vor dem Punkt ist die Gesamtbreite: 5.2f. Zahlen werden standardmäßig rechtsbündig aufgefüllt, also landet das Leerzeichen links. Die Hochkommas in ' 2.58' sind nur die Darstellung eines Strings in der Konsole.

Schritt 3 · Mit Nullen auffüllen

0000100 hat 7 Zeichen. Eine 0 direkt vor der Breite füllt mit Nullen statt Leerzeichen: f"{a:07d}". Gleichwertig: str(a).zfill(7).

Schritt 4 · Ausdrücke

In den geschweiften Klammern steht beliebiger Python-Code: f"{a*2}" ergibt 200. Soll a mehrfach vorkommen, geht auch "{0} {1} {0}".format(a, b).

Antwort: f"{b:5.2f}" → ' 2.58' · f"{a:07d}" → '0000100' · f"{a*2}" → '200'

Aufgabe 2

CSV einlesen & auswerten

📂

Hier geht es um Dateien und Funktionen: Eine CSV-Datei wird zeilenweise gelesen, Namen und Größen landen in zwei parallelen Listen – Index i gehört in beiden Listen zur selben Person. Die Auswertungsfunktionen nutzen genau diese Kopplung: Man sucht den Index des Minimums in heights und holt sich mit demselben Index den Namen.

Die Extras testen, ob die Funktion robust ist (kürzere Datei, vertauschte Spalten) und ob man verstanden hat, dass Funktionen in Python Objekte sind (min als Parameter).

Regeln

1 · Datei öffnenwith open(name, newline="", encoding="utf-8") as f: – schließt die Datei automatisch.
2 · Kopfzeilenext(reader) bzw. f.readline() überspringt die erste Zeile.
3 · DatentypAlles aus einer CSV ist str. Meter → float(), Zentimeter → int().
4 · Spalten per Namecsv.DictReader liefert pro Zeile ein Dict mit den Überschriften als Keys – die Spaltenreihenfolge ist dann egal.
5 · Index des Extremwertsi = heights.index(min(heights)) → names[i], heights[i]
6 · Funktion als Objektfunc = max (ohne Klammern) → func(heights) ruft max auf.

Lösungsweg

import csv

def read_csv_file(filename):
    names, heights = [], []
    with open(filename, newline="",
              encoding="utf-8") as f:
        reader = csv.reader(f)
        next(reader)             # Kopfzeile
        for row in reader:
            if not row:          # Leerzeile
                continue
            names.append(row[0].strip())
            heights.append(float(row[1]))
    return names, heights

def mean(heights):
    return sum(heights) / len(heights)

def shortest_person(names, heights):
    i = heights.index(min(heights))
    return names[i], heights[i]

def tallest_person(names, heights):
    i = heights.index(max(heights))
    return names[i], heights[i]

def min_max_person(names, heights, func):
    i = heights.index(func(heights))
    return names[i], heights[i]

def min_max_persons(names, heights, func):
    ziel = func(heights)
    return [n for n, h in zip(names, heights)
            if h == ziel]

Extra: Spalten vertauscht

def read_csv_file(filename, sep=","):
    names, heights = [], []
    with open(filename, newline="",
              encoding="utf-8-sig") as f:
        reader = csv.DictReader(
            f, delimiter=sep, skipinitialspace=True)
        for row in reader:
            names.append(row["Name"])
            heights.append(float(row["Größe"]))
    return names, heights

Extra: Dict zurückgeben

return dict(zip(names, heights))  # statt names, heights
✎ Klausur-Safe
  1. import csv und with open(...)
  2. Kopfzeile überspringen, dann über alle Zeilen iterieren – keine feste Anzahl, sonst scheitert personen_kurz.csv
  3. Größe in float (oder int) umwandeln
  4. return names, heights – zwei Rückgabewerte als Tupel, damit names, heights = read_csv_file(...) funktioniert
  5. mean: sum / len
  6. shortest/tallest: Index über min/max, Rückgabe names[i], heights[i]
  7. Extra: Funktion func als Parameter, Aufruf mit min ohne Klammern
  8. Extra: Listen-Comprehension über zip für mehrere Treffer
  9. Extra: DictReader für vertauschte Spalten

Aufgabe 3

Klassen & Vererbung

🧰

Eine Klasse bündelt Daten (Attribute) und Verhalten (Methoden). BesserePerson erbt alles von Person und überschreibt nur grow(), um eine Prüfung einzubauen. Die eigentliche Arbeit delegiert sie per super() an die Elternklasse – so steht die Logik nur an einer Stelle.

Das __repr__-Extra zielt auf einen Trick: Liest man den Klassennamen dynamisch über self.__class__.__name__, stimmt die Ausgabe automatisch auch für jede Unterklasse.

Regeln

1 · Konstruktordef __init__(self, name, height): – self ist immer der erste Parameter.
2 · Vererbungclass BesserePerson(Person): – übernimmt __init__, grow und __repr__.
3 · super()super().grow(amount) ruft die Methode der Elternklasse auf.
4 · Fehler werfenraise ValueError("Text") – bricht die Methode sofort ab.
5 · __repr__ vs. __str__print(obj) nutzt __str__, fehlt es, dann __repr__. Listen und Dicts zeigen ihre Elemente immer per __repr__.
6 · Klassennameself.__class__.__name__ bzw. type(self).__name__

Lösungsweg

class Person:
    def __init__(self, name, height):
        self.name = name
        self.height = height

    def grow(self, amount):
        self.height += amount

    def __repr__(self):
        cls = self.__class__.__name__
        return f"{cls}({self.name}, {self.height})"


class BesserePerson(Person):
    def grow(self, amount):
        if not 0 < amount < 10:
            raise ValueError(
                f"0 < amount < 10, war {amount}")
        super().grow(amount)


persons = {n: Person(n, h)
           for n, h in zip(names, heights)}
print(persons["Anna"]) → Person(Anna, 1.68)
✎ Klausur-Safe
  1. class Person: mit __init__(self, name, height), beide Attribute über self. speichern
  2. grow(self, amount): self.height += amount
  3. class BesserePerson(Person): überschreibt nur grow
  4. Bedingung 0 < amount < 10, sonst raise ValueError(...)
  5. Danach super().grow(amount)
  6. persons = {n: Person(n, h) for n, h in zip(names, heights)}
  7. Extra: __repr__ gibt einen String zurück, Klassenname über self.__class__.__name__
▸ Beispielaufgabe · BesserePerson benutzen
Schritt 1 · Objekt anlegen

p = BesserePerson("Max", 180) – BesserePerson hat kein eigenes __init__, also läuft das von Person.

Schritt 2 · Gültig wachsen

p.grow(5): 5 liegt in (0, 10) → super().grow(5) → height = 185. print(p) ergibt BesserePerson(Max, 185), obwohl __repr__ nur in Person steht.

Schritt 3 · Ungültig wachsen

p.grow(10): 0 < 10 < 10 ist False → ValueError. Abfangen mit try: p.grow(10) / except ValueError as e: print("Fehler:", e). Die Größe bleibt 185.

Antwort: BesserePerson(Max, 185) · Fehler: 0 < amount < 10, war 10
Achtung: Das Protokoll schreibt __repr(self)__ – richtig ist def __repr__(self): · __repr__ muss returnen, nicht printen · mit {self.name!r} erscheinen Anführungszeichen: Person('Anna', 1.68) · „größer 0 und kleiner 10“ schließt 0 und 10 selbst aus.

Mögliche Abweichungen

__str__zusätzliche lesbare Ausgabe, z. B. "Anna ist 1.68 groß"
Vergleiche__eq__ und __lt__ implementieren → sorted(persons.values()) funktioniert; alternativ max(persons.values(), key=lambda p: p.height)
Eigenes __init__Unterklasse mit zusätzlichem Attribut: super().__init__(name, height), dann self.matnr = matnr
Property@property + @height.setter, der negative Größen mit ValueError ablehnt; Wert intern in self._height
Klassenattributanzahl = 0 in der Klasse, im __init__ Person.anzahl += 1
classmethod / staticmethod@classmethod def from_row(cls, row) als alternativer Konstruktor · @staticmethod für Hilfsfunktionen ohne self
Typprüfung & Exceptionsisinstance(p, Person) ist auch für BesserePerson True · eigene Exception class GroesseError(ValueError): pass

Übung

Ergänze Person um __lt__ und sortiere das Dict persons nach Größe. Baue danach eine Klasse Kind(BesserePerson) mit zusätzlichem Attribut alter, deren grow() nur Werte kleiner 5 erlaubt – ohne die Prüfung aus BesserePerson zu kopieren.

Aufgabe 4

Package „height“

📦

Ein Modul ist eine einzelne .py-Datei, ein Package ein Ordner mit __init__.py, der Module enthält. Die Funktionen aus Aufgabe 2 werden nur auf zwei Dateien verteilt: Einlesen in read.py, Rechnen in calc.py. Python findet das Paket, wenn das Startskript im Ordner darüber liegt.

Regeln

1 · PaketOrdnername = Paketname; __init__.py (darf leer sein) markiert den Ordner als Paket.
2 · Importfrom paket.modul import funktion – ohne Klammern hinter der Funktion.
3 · Aliasimport paket.modul as kurz · from paket import modul as kurz · from paket.modul import f as g
4 · RelativInnerhalb des Pakets: from .read import read_csv_file (. = dieses Paket, .. = Elternpaket).
5 · __all__Liste der Namen, die from paket import * importiert.

└── height/
    ├── __init__.py

                   # tallest_person

✎ Klausur-Safe
  1. Ordnerbaum mit height/, __init__.py, read.py, calc.py hinzeichnen
  2. read.py: import csv + read_csv_file
  3. calc.py: mean, shortest_person, tallest_person

Im Protokoll heißt das Paket in den Importzeilen package_x – in der Klausur den tatsächlichen Paketnamen einsetzen.

▸ Beispielaufgabe · Was passiert beim Import?
Schritt 1 · Paket finden

from height.calc import mean: Python sucht im Startordner (und den Standardpfaden) nach einem Ordner height. Liegt main.py in projekt/, wird er gefunden.

Schritt 2 · __init__.py ausführen

Beim ersten Zugriff auf das Paket läuft height/__init__.py. Dort importierte Namen sind danach direkt am Paket verfügbar, z. B. from height import mean.

Schritt 3 · Modul laden

calc.py wird ausgeführt, mean landet im Namensraum von main.py. Mit as mittelwert heißt sie dort nur anders – es ist dieselbe Funktion.

Schritt 4 · Grenzen des Alias

from height import rechnen klappt, weil rechnen ein Attribut des Pakets ist. import height.rechnen dagegen sucht eine Datei rechnen.py und scheitert mit ModuleNotFoundError.

Antwort: Paket über Startordner finden → __init__.py → Modul → Name (ggf. mit Alias)
Achtung: from height.read import read_csv_file() ist ein SyntaxError · Start aus height/ heraus → ModuleNotFoundError · ein Modul mit from .x import direkt starten → ImportError, stattdessen python -m height.calc · eigene Dateien nie csv.py, string.py oder statistics.py nennen – sie überschatten die Standardmodule.
