Die Operatoren * und ** — Zerlegen vs. Sammeln

Kernidee: Beim Aufruf zerlegen die Sterne eine Sammlung in Einzelteile. In der Definition sammeln sie umgekehrt beliebig viele Argumente ein. * arbeitet mit Listen/Tupeln (Position), ** mit Dictionaries (Keyword).

① BEIM AUFRUF → ZERLEGEN

# * zerlegt Liste/Tupel in Positionsargumente
def addiere(a, b, c):
    return a + b + c

zahlen = [1, 2, 3]
addiere(*zahlen)      # → addiere(1, 2, 3) = 6
# statt addiere(zahlen[0], zahlen[1], zahlen[2])

# ** zerlegt Dict in Keyword-Argumente
def begruessung(name, alter):
    print(f"Hallo {name}, {alter} Jahre.")

daten = {'name': 'Max', 'alter': 25}
begruessung(**daten)  # → begruessung(name='Max', alter=25)

② IN DER DEFINITION → SAMMELN

# *args sammelt Positionsargumente → TUPEL
# **kwargs sammelt Keyword-Argumente → DICT
def f(*args, **kwargs):
    print('Tupel:', args)
    print('Dict: ', kwargs)

f(1, 2, 3, a='Apfel', b='Birne')
# Tupel: (1, 2, 3)
# Dict:  {'a': 'Apfel', 'b': 'Birne'}

# Namen frei wählbar (*args/**kwargs nur Konvention),
# der Stern macht die Arbeit, nicht der Name.
SchreibweiseKontextZweck
addiere(*liste)AufrufZerlegt Liste/Tupel in einzelne Positionswerte
begruessung(**dict)AufrufZerlegt Dict in Keyword-Argumente (key=value)
def f(*args)DefinitionSammelt beliebig viele Positionsargumente im Tupel
def f(**kwargs)DefinitionSammelt beliebig viele Keyword-Argumente im Dict

Faustregel: * für Listen, deren Elemente einzeln an eine Funktion sollen. ** für Konfigurations-Dicts, deren Werte direkt als Parameter weitergereicht werden. Auch beim Entpacken in Strukturen nutzbar: [*a, *b], {**d1, **d2}, a, *rest = [1,2,3,4] → rest=[2,3,4].

Klassen & Dunder-Methoden
class Dog:
    species = 'Canis...'   # Klassenattribut

    def __init__(self, name, age):
        self.name = name   # Instanzattribut
        self.age  = age

    def __repr__(self):    # maschinenlesbar
        return f'Dog({self.name!r},{self.age!r})'

    def __str__(self):     # menschenlesbar
        return f'{self.name} ({self.age} J.)'

    def __len__(self): return self.age

data = [('Rex',5),('Bella',2)]
dogs = [Dog(*x) for x in data]
dogs.sort(key=lambda d: d.age, reverse=True)

Fehlerbehandlung – try / except / finally
try:
    x = int(eingabe)          # Code, der fehlschlagen kann
except ValueError:
    print('Keine gültige Zahl')   # genau dieser Fehlertyp
except (TypeError, KeyError) as e:
    print('Fehler:', e)       # mehrere Typen, e = Objekt
except Exception as e:
    print('Sonstiger:', e)    # Auffangnetz (alle übrigen)
else:
    print('Kein Fehler')      # nur wenn KEIN except auslöste
finally:
    print('Läuft IMMER')      # Aufräumen, immer ausgeführt

raise ValueError('Meldung')   # Fehler selbst auslösen

Reihenfolge: spezifische except zuerst, Exception zuletzt. else nur ohne Fehler, finally in jedem Fall (auch bei return/raise).

lambda & Funktionen höherer Ordnung (key, map, filter)

LAMBDA – ANONYME FUNKTION

# lambda parameter: ausdruck
# → ein einziger Ausdruck, KEIN return, kein Name
double = lambda x: x * 2          # double(5) → 10
mult   = lambda x, y: x * y       # beliebig viele Args
const  = lambda: 42               # auch ohne Argument

# Entspricht:  def double(x): return x * 2
# Einsatz: direkt als key-/Argumentfunktion, wo sich
# keine eigene def-Funktion lohnt.

min / max / sorted MIT key=

nums = [3, -7, 2, -1]
min(nums)                     # -7  (nach Wert)
max(nums, key=abs)            # -7  (nach Betrag)

# Liste von Dicts – key wählt das Vergleichsfeld
data = [{'name':'A','age':5}, {'name':'B','age':2}]
min(data, key=lambda x: x['age'])  # {'name':'B','age':2}
max(data, key=lambda x: x['age'])

# Dict: min/max laufen über die SCHLÜSSEL
d = {'a': 5, 'b': 2}
min(d)                        # 'a'  (kleinster Schlüssel)
min(d, key=d.get)             # 'b'  (Schlüssel mit kl. Wert)
min(d.values())               # 2    (kleinster Wert)

map – AUF JEDES ELEMENT ANWENDEN

# map(funktion, iterable) → Iterator
list(map(lambda x: x**2, [1,2,3]))  # [1, 4, 9]
list(map(str, [1,2,3]))             # ['1','2','3']

filter – ELEMENTE AUSWÄHLEN

# filter(funktion, iterable) → Iterator
list(filter(lambda x: x>0, [-1,2,-3,4]))  # [2,4]
list(filter(None, [0,1,'','a']))    # [1,'a'] (truthy)

map/filter liefern Iteratoren → mit list(...) umwandeln (oft auch als Comprehension: [x**2 for x in nums]). key= erwartet eine Funktion mit einem Argument.
